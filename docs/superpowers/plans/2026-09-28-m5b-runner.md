# M5b Runner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved exact M5b runner, demonstrate durable recovery, and measure representative cells before any full study.

**Architecture:** A study-local numerical module handles finite hidden/output kernels and exact outer chains. One runner authenticates M5a, schedules bounded CPU jobs, checkpoints generation and replay separately, and produces bounded gzip evidence and operational provenance using existing persistence helpers.

**Tech Stack:** Python 3.11, NumPy float64, SciPy, pytest; existing locked dependencies only.

**Spec:** `docs/experiments/meta-ebm-finite-thermalization.md`

## Global Constraints

- Preserve all hash-bound M5a and hashing source files unchanged.
- Exact reference, zero samples, CPU only; no refitting or hardware claims.
- Caps 0.3, 1, 3, 10; K 1, 2, 4, 8, 16, 32; separate precision 4, 8, 12 bits.
- Both readings, five seeds, two methods: 80 references, 720 new cells.
- Local absolute tolerance 1e-12, local log tolerance 1e-8; adaptive local contraction <=1e-14, sweep TV <=2e-12; chain atol=1e-9, rtol=1e-8; stationarity residual <=1e-10.
- Autosave each generation/replay unit; bind reuse to request, source, archive and compatible runtime; completion last.
- At most four single-BLAS-thread dense workers; lower the limit for memory/CPU availability.
- Implement and benchmark only in this change; do not launch the full grid.

## Review Focus

- Strong couplings with lambda rounded to one must retain small positive rates, or fail explicitly (Task 1).
- Incoming output dependence, zero hidden spins and incompatible local conditionals must not collapse to memoryless updates (Tasks 1–2).
- Negative/ill-conditioned stationary solves must not be silently clipped into evidence (Task 2).
- Interrupted replay and a corrupt or mismatched checkpoint must never create completion or repeat completed generation (Task 3).
- Benchmark/subset artifacts must never be accepted as a complete production study; concurrent writers and false completion markers are rejected (Task 3).
