# Lessons

*Started October 3, 2026. One dated entry per lesson Thermo has learned from
its own recorded studies and reviews. A lesson here restates what a report or
research note already says; it is not new evidence. The evidence class in each
entry is copied from the cited source. Newest first.*

## How to add an entry

One entry per lesson, in the table below. The `Evidence class` column uses the
cited source's own words (`exact_reference`, `software_simulation`,
exploration, review). A lesson from a negative result is stated as negative.
Link the report or note that states it; the knowledge-base checker verifies
links in every file under `docs/knowledge/`. Do not add entries for results
that have no report or note yet.
