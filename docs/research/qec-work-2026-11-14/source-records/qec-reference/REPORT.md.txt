## Conservative counting on actual d5

Dropping checks creates a superset event, so its mass bounds the full class from above. Partial feasible configuration sums bound from below. Outward-rounded longdouble arithmetic applies nextafter to each elementary coefficient subtraction, product and sum. Exact rational representations of endpoints are saved. Numerical guarantee is conditional on correctly-rounded IEEE elementary arithmetic/nextafter on this platform, for exact BINARY64 probabilities supplied by Stim; it is not a formal platform-independent proof or a bound on hypothetical decimal-intended parameters. Independent Fraction.from_float exhaustive tests cover edge probabilities, dependent constraints and duplicates.

## Conclusion
We now have verified model mapping, an external exact small fixture and conservative but loose actual-d5 bounds. We do NOT yet have a trustworthy tight d5 reference for captured class mass.
