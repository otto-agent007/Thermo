# Targeted d5 diagnostic: frozen prespecified diagnostic

Goal: determine where the unchanged16-candidate logical-class mass proxy repairs or harms strong decoders, and whether certified full-class ordering reveals residual headroom. This is not a powered efficacy or population superiority study.

Freeze source hashes, versions, screen rule, evaluation rule and budgets BEFORE screening. Screen reads detectors and saved correlated predictions only, never observed logical labels or full-class reference values. For agreement cases use an explicitly approximate logical-decision margin from beliefmatching's BP marginal LLRs: independent-parity proxy Eproxy[(-1)^L] ≈ product_{merged BP variables with logical bit1}tanh(LLR/2), Pproxy0=(1+E)/2; rank by abs(log(Pproxy0/Pproxy1)), clipped only to avoid infinite logs. A fresh BM instance is used per shot to eliminate history dependence; this setup cost counts. Zero-detector syndromes have missing close proxy by prespecified rule (BP early-exit marginal state can be uninformative); controls/disagreement eligibility otherwise unchanged. BP dependencies/correlations ignored; not calibrated, not true class posterior. Record convergence and Tesseract low-confidence flag; neither is a correctness certificate. Nonfinite proxy is missing, never silently replaced.

Selection is deterministic from frozen seed20261114 and source identities. Per cell choose at most1 case from each of3 disjoint strata:
1. Before reading screen values, uniformly select one ordinary shot from the full256-index pool using frozen RNG; this stratum is not conditioned on agreement or proxy.
2. Excluding the ordinary shot and its same-cell detector syndrome, uniformly choose one unique-syndrome strong-decoder disagreement (correlated/Tesseract/BM not unanimous).
3. Among remaining unanimous unique-syndrome cases with finite proxy, choose smallest absolute proxy margin (ties lowest index); call this proxy-close, not genuinely close until reference evaluated.
No observed labels or references used. A missing stratum is explicitly absent, with no cross-cell replacement. For targeted strata deduplicate identical detector syndromes within each cell to lowest-index representative, preserving multiplicities; ordinary selection remains uniform over shots, not unique syndromes. Cases across different cells are distinct model strata.

Freeze selected indices and screen provenance in immutable selection manifest BEFORE evaluation reads observed labels. Maximum18 selected cases. This balanced targeted design measures conditional diagnostic behavior, not full-archive logical error rate. Ordinary stratum has only one random shot per cell, so no useful power for rare-error efficacy; targeted observations cannot be pooled into that ordinary estimate.
