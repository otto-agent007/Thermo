# Six fresh saved-case diagnostic

Selection is index32 in each of six archived d5 settings. All prior sampler/pilot cases0–31 are excluded. No selected outcomes were inspected before plan/source freeze. This is six development diagnostics, not a population efficacy study.

Run only after owner authorization and independent pre-run review. runner.py verifies manifest and authorization before reading selected arrays. It enforces3GiB address-space,3600CPU-second total, and600CPU-second per-case hard signal limits. All costs count against total; startup/import/manifest verification precede per-case timers. A hard cap may terminate without cleanup, leaving a status file saying running. Missing completion plus process exit is INCOMPLETE, not success. Never replace/drop a timed-out case or silently expand.

Candidates4/16 are prefixes of a feasible MILP portfolio, not a claim of exact top-k enumeration if solver timed out. Conditional numerical intervals follow the independently reviewed one-case arithmetic analysis with per-model structure/precision guards. Portfolio coverage intervals, class-ordering intervals, inconclusive cases and observed-label comparisons must be reported separately.

Existing matching outputs are archived predictions: no matching-runtime measurement is made in this diagnostic. New candidate, comparator and reference times are measured separately. A reference calculation is not production decoding overhead unless explicitly included in a proposed production algorithm.

Preserve every completed case and slice checkpoint to Library. Independent saved-output review is required before findings are final.
